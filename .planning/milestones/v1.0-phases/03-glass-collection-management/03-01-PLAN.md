**SVG Illustrations:**

Create 8 SVG files in `public/assets/glasses/` — one for each glass type. Requirements:
- Simple line-art style, monochrome (use `currentColor` for stroke so CSS can control color)
- Consistent viewBox (e.g., `0 0 100 120` or similar)
- Consistent stroke width (2-3px)
- Each SVG should be recognizably different — capture the distinctive silhouette of each glass type:
  - **pint.svg** — straight-sided tapered glass, wider at top
  - **tulip.svg** — bulbous bottom curving inward then flaring out at top, short stem
  - **snifter.svg** — wide round bowl narrowing at top, short stem
  - **weizen.svg** — tall, narrow at bottom, curves outward in middle, narrows slightly at top
  - **goblet.svg** — wide round bowl on a tall stem with a base
  - **pilsner.svg** — tall, slim, tapers from wider top to narrow bottom, no stem
  - **stange.svg** — narrow cylindrical glass, straight sides, no taper
  - **mug.svg** — thick cylindrical glass with a handle on one side
- Keep SVGs clean and minimal (under 20 lines each). No fills, stroke only.
- Each SVG should work at sizes from 64px to 200px.

**Firestore Security Rules:**

Create `firestore.rules` at project root with:
```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId} {
      allow read: if request.auth != null && request.auth.uid == userId;

      match /glasses/{glassId} {
        allow read: if request.auth != null && request.auth.uid == userId;
        allow create: if request.auth != null && request.auth.uid == userId;
        allow delete: if request.auth != null && request.auth.uid == userId;
        allow update: if request.auth != null && request.auth.uid == userId;
      }
    }
  }
}
```

This ensures:
- Only authenticated users can access their own data
- Glass subcollection operations require matching userId
- No cross-user access is possible
- Update is included for editing glass size later
