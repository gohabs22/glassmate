  <action>
Create 4 files under the `(dashboard)/glasses/` route group. All pages within `(dashboard)` are protected by middleware (requires `__session` cookie). All pages are Client Components because they use `useAuth()` hook and handle user interactions.

**1. `src/app/(dashboard)/glasses/page.tsx`** — Glass Collection Page
- 'use client' component
- Use `useAuth()` to get current user
- Use `useEffect` + `useState` to fetch user's glasses via `getUserGlasses(user.uid)` on mount
- State: `glasses: GlassInCollection[]`, `loading: boolean`
- Handle loading state: show `GlassCatalogSkeleton` while loading
- Handle auth loading: show loading spinner if `useAuth().loading` is true
- Redirect to `/login` if not authenticated (same pattern as dashboard page)
- Pass `glasses`, `onRemove`, and `onUpdateSize` callbacks to `<GlassCollection />`
- `onRemove` calls `removeGlassFromCollection(user.uid, glassId)` then refetches glasses
- `onUpdateSize` calls `updateGlassInCollection(user.uid, glassId, newSize)` then refetches glasses
- Page header: "My Glass Collection" with subtext showing count (e.g., "3 glasses")
- Navigation: Link to "/glasses/catalog" ("Browse Catalog") and Link to "/glasses/guide" ("Glass Guide")
- Use layout: page title section at top, navigation links, then the collection grid

**2. `src/app/(dashboard)/glasses/catalog/page.tsx`** — Glass Catalog Page
- 'use client' component
- Use `useAuth()` to get current user
- Fetch user's existing glasses to mark which are already in collection
- Pass `userGlasses` and `onAdd` callback to `<GlassCatalog />`
- `onAdd` calls `addGlassToCollection(user.uid, glassType, size)` then refetches glasses
- After successful add, show brief visual feedback (button changes to "Added!")
- Page header: "Glass Catalog" with subtext "Browse and add glass types to your collection"
- Navigation: Link back to "/glasses" ("My Collection") and Link to "/glasses/guide" ("Glass Guide")

**3. `src/app/(dashboard)/glasses/guide/page.tsx`** — Glass Guide (Dashboard)
- 'use client' component
- Use `useAuth()` to get current user (for conditional "Add to Collection" buttons)
- Renders all glass types from `GLASS_CATALOG` using `<GlassGuideCard />` in a grid
- If user is authenticated, show "Add to Collection" buttons on each guide card
- `onAdd` calls `addGlassToCollection(user.uid, glassType, size)` (if authenticated)
- Page header: "Glass Type Guide" with subtext "Learn about different beer glass types and their ideal pairings"
- Navigation: Link back to "/glasses" ("My Collection") and Link to "/glasses/catalog" ("Browse Catalog")

**4. `src/app/(dashboard)/glasses/loading.tsx`** — Loading State
- Export default component that renders `<GlassCatalogSkeleton />` inside a container matching the page layout
- This is a Server Component (no 'use client' needed) — Next.js uses it automatically during page transitions

**Shared page patterns:**
- All pages use consistent header styling: `text-2xl font-bold text-gray-900` for title, `text-gray-600` for subtext
- Navigation links use: `text-amber-600 hover:text-amber-700 font-medium` styling
- Use `useCallback` for handler functions passed to child components to prevent unnecessary re-renders
- Error handling: wrap Firestore calls in try/catch, show inline error message on failure
