  <action>
    Create `src/components/beer/ResultsSheet.tsx` — a 'use client' component using react-modal-sheet.

    Props:
    - `matchResult: MatchResult | null`
    - `isOpen: boolean`
    - `onClose: () => void`
    - `onSaveToHistory: () => void` — called when user taps "Save to history"
    - `isLoggedIn: boolean` — determines whether to show save button or signup nudge
    - `saved: boolean` — whether this match has already been saved

    Implementation:
    - Import `{ Sheet }` from `react-modal-sheet` (named import, NOT default)
    - Use `detent="content"` (NOT "content-height")
    - Return null if matchResult is null

    Layout (inside Sheet.Content):

    **1. Compact beer recap** (top section):
    - Beer name (text-lg font-semibold)
    - Style badge (amber-100 bg, amber-800 text, rounded-full pill) + ABV
    - Brewery name (text-sm text-gray-500)

    **2. Empty collection case** (when matchResult.idealGlass is set):
    - Show ideal glass name and description
    - Message: "You'll want a {glass name} for this {style}. Let your host know!"
    - No save button in this case

    **3. Recommended glasses section** (when matchResult.recommendedGlasses.length > 0):
    - Section header: "Recommended" (text-sm uppercase tracking-wide text-gray-500)
    - Each glass as a row:
      - Green dot (w-2.5 h-2.5 rounded-full bg-green-500) + glass name (font-medium) + size
      - Rationale text below (text-sm text-gray-600, two lines)
      - Rank number on the left or as "#1", "#2" prefix

    **4. Other glasses section** (when matchResult.otherGlasses.length > 0):
    - Section header: "Other options"
    - When NO recommended glasses exist, show disclaimer above list: "Not an ideal match, but your best bet:"
    - Each glass as a row:
      - Gray dot (bg-gray-400) + glass name + size
      - Generic rationale (text-sm text-gray-500)

    **5. Save to history section** (bottom):
    - If `isLoggedIn && !saved`: "Save to history" button (amber-600, full width)
    - If `isLoggedIn && saved`: "Saved!" text (text-green-600, checkmark)
    - If `!isLoggedIn`: Gentle nudge text: "Sign up to save your beer history" with link to /signup

    **No explicit close button** — user swipes down or taps backdrop to dismiss.

    Style: Tailwind, consistent with app's amber-600 accent. Clean spacing between sections with dividers (border-t border-gray-100).
  </action>

    }}

      matchResult={matchResult}
