    1. Install dependencies:

    2. Create `src/components/qr/QRCodeDisplay.tsx` as a 'use client' component:
       - Props: `{ userId: string }`
       - Build check-in URL using `window.location.origin + '/c/' + userId`
       - Use `useState` for `checkInUrl` (empty string initially), populate in `useEffect` from `window.location.origin`
       - Use `useState` for `canShare` (boolean), detect Web Share API file support in `useEffect`
       - Render `QRCode` from `react-qr-code` with: size=256, level="M", bgColor="#ffffff", fgColor="#000000"
       - Wrap QR code in a div with id="qr-code-container" and white background padding (16px) for quiet zone
       - Display the check-in URL as copyable text below the QR code
       - Download button: uses `toBlob` from `html-to-image` on the container element, creates anchor with `link.download = 'my-collection-qr.png'`, clicks, then calls `URL.revokeObjectURL(url)` to prevent memory leaks
       - Share button (only shown when `canShare` is true): converts to blob, creates File, calls `navigator.share({ files, title, text })`, catches AbortError silently, falls back to download on other errors
       - When `canShare` is false, only show download button (no share button at all)
       - Amber-600 color scheme for buttons, consistent with project design
       - Loading state: show "Loading..." while checkInUrl is empty string
  </action>

    Run `npx tsc --noEmit` to confirm no type errors. Verify `react-qr-code` and `html-to-image` are in package.json dependencies.
  </verify>

  </done>
