  <action>
    **Create `src/components/beer/BeerSearch.tsx`:**

    A 'use client' component implementing debounced autocomplete search.

    Props:
    - `onSelect: (beer: Beer) => void` - called when user selects a beer from results

    Implementation:
    - Use `Combobox`, `ComboboxInput`, `ComboboxOptions`, `ComboboxOption` from `@headlessui/react`
    - Use `useDebounce` from `use-debounce` with 300ms delay
    - State: `query` (string), `debouncedQuery` (from useDebounce), `results` (Beer[]), `loading` (boolean), `error` (boolean)
    - `useEffect` on `debouncedQuery`:
      - If length < 2, clear results and return
      - Create AbortController
      - Call `searchBeers(debouncedQuery, signal)`
      - Set results on success
      - On error: if not AbortError, set error=true (triggers fallback messaging)
      - Cleanup: abort controller
    - Combobox `onChange` calls `onSelect` with the selected Beer
    - ComboboxInput: placeholder "Search for a beer...", onChange updates query
    - ComboboxOptions (dropdown):
      - Loading state: "Searching..." text
      - No results + query >= 2 chars: "No beers found. Try browsing by style below."
      - Error state: "Search unavailable. Browse by style below."
      - Results: Each ComboboxOption shows `{beer.name}` on first line, `{beer.brewery}` in smaller text below
    - Style with Tailwind: white dropdown bg, rounded-lg shadow, amber-600 highlight on active option, proper padding

    IMPORTANT anti-patterns to avoid (from RESEARCH.md):
    - Do NOT set `value={query}` on Combobox root. Input manages query, Combobox manages selection.
    - Do NOT create debounce function in render body. Use the `useDebounce` hook.
    - ALWAYS cancel old requests via AbortController cleanup in useEffect return.

    **Create `src/components/beer/StyleBrowser.tsx`:**

    A 'use client' component for browsing beer styles by category.

    Props:
    - `onSelectBeer: (beer: Beer) => void` - called when user picks a specific beer from examples

    Implementation:
    - Import `BEER_STYLE_CATEGORIES` from `@/lib/beer/styles`

    - Render categories as sections with h3 headers
    - Each style is a button that toggles `expandedStyle`
    - When a style is expanded, show its example beers as clickable items below it
    - Clicking an example beer calls `getExampleBeer` to create a Beer object, then calls `onSelectBeer`
    - Include style description and ABV range in each style row
    - Tailwind styling: consistent with app's amber-600 accent, clean spacing, clear visual hierarchy
    - Collapsible sections: chevron icon rotates when expanded (use a simple SVG chevron, no icon library needed)
  </action>
