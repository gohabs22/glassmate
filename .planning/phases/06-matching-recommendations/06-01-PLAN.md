    **Types:**
    ```typescript
    export type MatchTier = 'recommended' | 'other';

    export type MatchedGlass = {
      glass: GlassType;
      size: string;
      tier: MatchTier;
      rationale: string;
      rank: number;
    };

    export type MatchResult = {
      beer: Beer;
      recommendedGlasses: MatchedGlass[];
      otherGlasses: MatchedGlass[];
      hasIdealMatch: boolean;
      bestAvailable: MatchedGlass | null;
      idealGlass: GlassType | null; // For empty host collection case
    };
    ```

    **Main function: `matchBeerToGlasses`**
    ```typescript
    export function matchBeerToGlasses(
      beer: Beer,
      hostGlasses: { glassType: GlassType; size: string }[]
    ): MatchResult
    ```

    Logic:
    1. If hostGlasses is empty, find the ideal glass from GLASS_CATALOG where beerStyles includes beer.style, return MatchResult with `idealGlass` set and empty recommended/other arrays
    2. For each host glass, check if `glass.beerStyles.includes(beer.style)`:
       - If yes → recommended tier, get pairing rationale via `getPairingRationale(glassId, beerStyle)`
       - If no → other tier, get generic rationale via `getGenericRationale(glassId)`
    3. Assign rank numbers (1, 2, 3...) within each tier
    4. Set `hasIdealMatch = recommended.length > 0`
    5. Set `bestAvailable` = first recommended glass, or first other glass if no recommended

    **Pairing rationale data:**
    Create a `PAIRING_RATIONALE: Record<string, string>` map with keys as `"glassId:beerStyle"`.

    IMPORTANT: Write rationale for EVERY glass-style combo that exists in the glass catalog beerStyles arrays (including the 5 newly added ones). Use the rationale text from 06-RESEARCH.md as a starting point. Each entry is two sentences, casual pub vibe.

    The rationale map keys must match EXACTLY what's in the glass catalog. For example:
    - `"pint:Pale Ale"` — because pint glass has "Pale Ale" in beerStyles
    - `"pint:IPA"` — because we just added "IPA" to pint glass
    - `"tulip:Saison"` — because tulip glass has "Saison" in beerStyles

    Cover ALL glass-style combos (should be ~45 entries after adding the 5 new ones).

    **Generic rationale data:**
    Create `GENERIC_RATIONALE: Record<string, string>` with one entry per glass ID (8 total). One sentence, casual. Used for "other" tier glasses.

    Use the rationale text from the research file (06-RESEARCH.md Pairing Rationale Database section) as your source. Adapt as needed for any new combos.
  </action>
