<task type="auto">
  <name>Task 2: Configure dev branch, branch protection, and merge strategy</name>
  <files></files>
  <action>
1. Create and push the dev branch:
   ```
   git checkout -b dev
   git push -u origin dev
   git checkout main
   ```

2. Apply branch protection on main via GitHub REST API. Write this JSON to a temp file and pass with --input:
   ```json
   {
     "required_status_checks": null,
     "enforce_admins": true,
     "required_pull_request_reviews": {
       "required_approving_review_count": 0,
       "dismiss_stale_reviews": false,
       "require_code_owner_reviews": false
     },
     "restrictions": null,
     "allow_force_pushes": false,
     "allow_deletions": false
   }
   ```
   ```
   gh api --method PUT repos/gohabs22/glassmate/branches/main/protection --input protection.json
   ```
   This enforces: PRs required to merge (no direct pushes), 0 reviewers needed (can merge own PRs), no admin bypass (enforce_admins=true), force pushes blocked.

3. Configure merge strategy — merge commits only (per discretion: preserves granular commit history, aligns with user's value of "project history visible in repo"):
   ```
   gh repo edit gohabs22/glassmate --enable-merge-commit --disable-squash-merge --disable-rebase-merge
   ```

4. Verify branch protection is active:
   ```
   gh api repos/gohabs22/glassmate/branches/main/protection --jq '{pr_required: .required_pull_request_reviews.required_approving_review_count, enforce_admins: .enforce_admins.enabled, force_push: .allow_force_pushes.enabled}'
   ```
   Expected: pr_required=0, enforce_admins=true, force_push=false

5. Functional verification — confirm direct push to main is rejected:
   ```
   echo "# protection test" >> README.md
   git add README.md
   git commit -m "test: verify branch protection"
   git push origin main
   ```
   This push MUST be rejected. After confirming rejection:
   ```
   git reset HEAD~1
   git checkout -- README.md
   ```

Clean up the temp protection.json file after use.
  </action>

- `gh api repos/gohabs22/glassmate/branches/main/protection` returns 200 with correct settings
- `git branch -r` shows both origin/main and origin/dev
- Direct push to main is rejected (verified by test push attempt)
- `gh repo view gohabs22/glassmate --json mergeCommitAllowed,squashMergeAllowed,rebaseMergeAllowed` shows only mergeCommit=true
  </verify>
